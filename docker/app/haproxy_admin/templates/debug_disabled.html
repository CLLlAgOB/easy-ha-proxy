Diagnostic routes are disabled

This is the secure default. The diagnostics button is hidden and routes exposing technical data are unavailable.

How to enable temporarily

  1. Add this to /etc/easy-ha-proxy/vars.yml: 
    haproxy_admin_debug_routes: true
  2. Apply the current configuration: 
    sudo easy-ha-proxy update --no-fetch

After diagnostics, set the value to false and run the same command again.
