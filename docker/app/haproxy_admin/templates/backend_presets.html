Backend sets

A backend set is a named list of backend addresses, each with its role: primary or backup. Sites, TCP proxies and UDP forwards can pick a set instead of typing the addresses again.
Changing a set changes every entry that uses it. Sites and TCP proxies take the change when the HAProxy configuration is validated and applied; UDP forwards are applied at once.
