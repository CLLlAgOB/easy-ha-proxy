A hook is already delivering certificates

These scripts were written by hand before this page existed, and they still run. They are left alone deliberately: whatever they do is working. If you configure a target here for the same certificate, it will be sent twice — harmless, but you probably want to remove the old script once you are satisfied the new target works.

Targets

Machines other than this gateway that need the same certificate: a Remote Desktop Gateway that wants a PKCS#12 file, a web server that wants the PEM pair, an appliance that wants both concatenated. Each target names the certificates it wants, and is sent them a few seconds after they renew.

Delivery runs after HAProxy has already reloaded, so a machine that is switched off cannot leave this gateway on an old certificate. One target failing does not stop the others.
