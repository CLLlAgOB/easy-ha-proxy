Delivery

Email uses the notification settings the certificate notices already use. A site with its own alert address keeps it: that address belongs to the site, not to this page.

Webhook

One JSON object per notification, over HTTPS only. The address is resolved once and the connection is made to exactly that address, so a name that answers differently on a second lookup cannot redirect the request inward. Loopback and link-local destinations are refused, private ones only with the switch below. Redirects are never followed. The URL and the header value are stored root-only and are never sent back to this page.

Conditions

A delay of zero means the first observation is enough. The repeat window is how long a condition stays quiet before it says so again. A site with its own value in its settings overrides the delay here.
