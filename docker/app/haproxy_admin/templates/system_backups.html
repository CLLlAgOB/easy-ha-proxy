Copies on another machine

An encrypted archive sitting on the server it would rebuild is not a backup of that server. A destination pushes the finished archive somewhere else over SFTP. Only the already-encrypted file is sent: the passphrase stays here and nothing is unpacked on the way.

The host key you pin is the one that will be accepted, and nothing older is removed on the far end until the new copy has been verified there. The private key and the host key are stored root-only and are never sent back to this page.

The upload carries the archive's SHA-256 in its signature, so the storage service refuses a body that does not match it. A successful upload is already proof the far end holds these exact bytes, with no second transfer to check.
