Security update policy

System settings remain in effect until you explicitly enable panel management. Managed modes pause the native APT upgrade timer; system mode restores its previous state.

The installation window uses the server's local time. Saving a managed policy may install the distribution security tools. It does not install pending security updates immediately.

Daily installation starts at the selected server hour. Busy maintenance delays it within that hour; a missed hour waits until the next day.

Automatic reboots follow the separate reboot policy below. Package updates may restart other affected services. HAProxy, Docker and active maintenance services require a controlled restart.

Scheduled server reboot

Reboot when Linux requires it after an update. The optional service fallback below also permits a reboot for verified deferred service restarts. All sites are briefly unavailable during a reboot.

Service fallback requires enabled service restart maintenance and a successful run in its latest window. Failed or unknown checks never authorize a reboot.

The selected time starts a one-minute countdown with a cancel button. Busy maintenance postpones the reboot within one hour; a missed window waits until the next day.

Enable a managed security update mode above to configure scheduled reboots. Native Linux reboot settings remain visible under current settings.
