A bounded window over recent requests, kept so a failed request can be found again -- not a log pipeline. The query string is dropped before anything is stored; of the headers only the User-Agent is kept, as the access log writes it, and no cookie or body. The size cap is what actually holds the store down, not the retention window, and writing stops before the filesystem reserve is touched.
