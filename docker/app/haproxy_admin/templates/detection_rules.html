Request tester

Check a request without banning anyone. Parameters are analysed temporarily and are not saved. History, cooldowns and gateway decisions can change the live score.

Context and observation

New rules start in observation. Trusted addresses only produce warnings; observations never turn into old ban points after a mode change. HAProxy hard limits stay active.

Site rules
Narrow exceptions

An exception only skips its selected rule on the chosen site, methods and route. Other attack rules still apply.

Rule modes and statistics

Counters cover up to 24 hours. Unique IP counts are capped at 64 per rule. Capacity evictions mean some observations were lost.

Existing behavioral rules

Application profiles

Profiles explain expected methods and routes. They do not bypass protection; use a narrow exception for a verified false positive.

Your rules

Rules added here are kept separately from the list that ships with the software, and are applied on top of it. That matters both ways: a deploy replaces the shipped list and cannot take yours with it, and a shipped signature you switch off stays off when the list is next updated. A signature that caused a false ban must not come back with a release.

A signature that begins with a slash matches the whole path. Anything else matches one path segment wherever it appears, so a signature of acme-console also catches /x/acme-console/login.

Trap names

Names that point at this gateway but serve no site. Nobody with a reason to be here asks for one; scanners find them in public certificate logs. A request for a trap name bans the address at once, unless that address otherwise uses the gateway like an ordinary client: an old bookmark is spared and only counted.

Suggested by traffic

Paths that no rule matches, refused to at least three different addresses and never served to anyone. Add one as a signature, or hide it. Paths that ordinary clients asked for too are listed last and marked: those are more likely a broken link than a probe.

Shipped rules

What the engine looks for in a request. A decisive category is one no client has any business asking for, so a single hit is enough on its own. The rest are only probable: a site may genuinely run WordPress or serve something under /vendor, so one hit there is not enough by itself.

Switch off any signature that is matching your own traffic. It stays off across updates, and you can switch it back on here.

Programs that name themselves in the User-Agent header. Attack tools ban on one request; internet-wide surveys only count towards a ban. Generic libraries such as curl are not listed, because monitors use them too. These come with the shipped list and are not switched off here.

The shipped list is a file on the gateway, replaceable without rebuilding anything. A broken or missing one keeps the built-in rules rather than switching detection off.
