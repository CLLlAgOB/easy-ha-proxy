Errors / error-based bans

Error-rate threshold for this site. Used in ACL form: src_http_err_rate(tbl_err_SITE) gt err_limit. If IP for this site generates more errors, than err_limit (in window err_window), IP may be added in tbl_ban. Empty — use the default value (from site_defaults.err_limit or default 8).
Time window used to count errors and storage entries stick-table. Examples: 10s, 20s, 1m. A shorter window reacts faster and more aggressively to error spikes. Empty — use the default value (from site_defaults.err_window or default 20s).
