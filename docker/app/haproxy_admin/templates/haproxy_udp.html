A forward takes the set's first primary address as the backend and its first backup address as the backup.
With a backup, the main backend is checked every 5 seconds. After three missed checks in a row the forward sends to the backup, and returns once the main backend has answered for 30 seconds; flows already under way move at once. The backup is checked the same way and is not used while it does not answer either.
